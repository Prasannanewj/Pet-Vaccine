# Pet-Vaccine

Pet flu vaccine marketing strategy and launch planning.

## Owner promotion prototype

Open [index.html](index.html) directly, or run `python3 -m http.server 8765` in this directory and visit `http://localhost:8765`. The canine influenza experience is an illustrative, local-only prototype; its sample content and clinic listings are not live or redeemable.
