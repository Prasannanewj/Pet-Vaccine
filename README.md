# Pet-Vaccine

Pet flu vaccine marketing strategy and launch planning.

## Owner promotion prototype

On Windows, double-click [run-local.bat](run-local.bat). It starts the site from the repository folder and opens `http://localhost:8765/` in your default browser. Keep the server window open while testing. Python 3 must be installed; if port 8765 is occupied, stop the other server and try again.

On macOS or Linux, open a terminal in this directory and run `python3 -m http.server 8765`, then visit `http://localhost:8765/`. The canine influenza experience is an illustrative, local-only prototype; its sample content and clinic listings are not live or redeemable.
